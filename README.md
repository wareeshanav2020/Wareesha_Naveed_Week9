# Olist E-Commerce Business Intelligence

## Phase A — Data Analysis and Modelling
In Phase A, I analyse the Olist E-Commerce dataset to understand business performance and data quality. I perform data cleaning, exploratory data analysis, customer segmentation, sales forecasting, and predictive modelling to identify useful business insights.

## Phase B — Dashboard and Decision Support
In Phase B, I use the results from Phase A to support business decision-making through a Streamlit application. The dashboard presents business summaries, customer segments, sales trends, forecasting results, model predictions, and feature importance, depending on the available data and trained model.

## Run the Application
Install the required packages:

```bash
pip install -r requirements.txt
```

Start the dashboard:

```bash
streamlit run app.py
```

Ensure the required CSV files and trained model are available and compatible with the application.

## Conclusion
Both phases combine data analysis, machine learning, and dashboard visualisation to provide insights into customer behaviour, sales performance, and potential business improvements.
